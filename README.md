# Tower Defense Game

A simple Tower Defense game built by me

The goal is to stop enemies from reaching the end of the path by placing towers on the map.
Towers automatically attack nearby enemies....and you earn gold by defeating them. 
As the waves increase, enemies become stronger and the game becomes more challenging.

## Features

* Enemy wave system ( all enemies comes in group )
* Tower placement (  you can place the tower anywhere at the map )
* Once you placed the tower on map it will automatically hit the enemies
* also enemy have some health... which decay at every shot from the tower
* Gold and economy system
* Game over system when you loose
* Restart button so you can try again
* Tower attack range 
* the more higher you will kill the higher rewards will be there

## How to Play

1. Click Start Game to begin.
2. Place towers on the map by clicking anywhere on the field.
3. Each tower costs gold.
4. Towers automatically attack enemies within range.
5. Earn gold by defeating enemies.
6. Prevent enemies from reaching the end of the path.
7. The game ends when all lives are lost.
